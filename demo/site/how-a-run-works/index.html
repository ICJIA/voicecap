How a run works

voicecap opens each page and goes through it three times.

Each time is a pass, and each pass gets its own transcript.

The read pass

The screen reader reads the page from top to bottom, one line at a time.

The headings pass

It jumps from heading to heading, to hear the page's outline.

The tab pass

It presses Tab from link to link and field to field, as a keyboard user does.

This demo site comes with voicecap, for trying it out.
