Before you start

Two commands get a computer ready for voicecap, and keep it that way.

voicecap setup

Setup installs what voicecap needs on this computer.

On Windows, that includes voicecap's own copy of NVDA, so yours stays as it is.

On a Mac, setup also walks you through the permissions macOS asks for.

voicecap doctor

Doctor checks the screen reader, the browser, and anything else that could stop a run.

Then it starts the screen reader for a 20-second live test.

The tour ran the same checks, and the live test, in steps 2 and 3.

This demo site comes with voicecap, and runs only on this computer.
